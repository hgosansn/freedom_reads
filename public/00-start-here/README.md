# Start Here

This course teaches a decision process, not trade signals. Complete it in order because each layer constrains the next: context, location, behavior, trigger, execution, risk, then review.

## Prerequisites

Before using the entry library, you should be able to:

- read OHLCV charts without future bars;
- distinguish market, limit, stop-market, and stop-limit orders;
- calculate percentage change, notional, fees, and loss at a stop;
- export venue trades and verify order status;
- use replay or simulation without risking live capital;
- keep emergency and living funds outside trading capital.

## Completion path

1. Read Foundations through Order Flow and define every term in the [Glossary](glossary.md).
2. Specify one entry model with the Frozen Model Specification.
3. Complete the worked cases without revealing later information.
4. Validate the model under the Research and Validation protocol.
5. Complete the [Assessment Rubric](assessment-rubric.md).
6. Begin any live deployment only at the reduced risk allowed by the Risk Framework.

Use the [Planning and Journal Templates](templates.md) for every simulated and live decision.

{% hint style="danger" %}
Course completion does not establish profitability. It establishes that a model is explicit enough to test and that risk decisions can be audited.
{% endhint %}
