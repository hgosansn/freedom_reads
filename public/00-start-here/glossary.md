# Glossary

| Term | Operational definition |
|---|---|
| Acceptance | Sustained trade and value formation beyond a reference under a frozen time, close, and volume rule |
| Rejection | Failure to remain beyond a reference followed by a defined return and response |
| Balance | Overlapping trade around relatively stable value under a frozen classification rule |
| Imbalance | Directional price discovery with expanding range and migrating value |
| POC | Price with the greatest volume inside the specified profile |
| VAH / VAL | Upper and lower boundaries of the specified value-area calculation |
| HVN / LVN | Relatively high or low volume zone inside a specified profile and threshold rule |
| Failed auction | Attempted discovery outside a reference that fails the rejection rule and returns into the prior auction |
| Delta | Buyer-initiated volume minus seller-initiated volume for a stated feed and classification method |
| CVD | Cumulative delta with a stated venue set, start time, and reset rule |
| Absorption | Aggressive volume meets passive liquidity with limited price progress, then confirms under a frozen response rule |
| Exhaustion | Declining aggressive participation near an extreme, confirmed by failed continuation |
| Invalidation | Observable condition that disproves the trade thesis |
| Stop trigger | Price reference that activates a conditional protective order |
| Mark price | Venue fair-price reference commonly used for margin and liquidation |
| Portfolio heat | Estimated loss if all open positions reach planned stops |
| MAE / MFE | Maximum adverse or favorable excursion from the defined entry |
| R multiple | Net P&L divided by the trade's frozen initial risk |

A term is not operational until its timeframe, data source, thresholds, and timestamp are specified.
