# Pre-market

Crypto has no universal open, so “pre-market” means the scheduled preparation window before your trading session. Complete it before exposure changes your interpretation.

## Environment

- [ ] Check scheduled macro releases, central-bank events, token unlocks, protocol events, and major earnings relevant to crypto beta.
- [ ] Note funding, basis, open-interest extremes, and options expiry or large strike concentration where available.
- [ ] Confirm exchange status, deposits/withdrawals, data feeds, and order connectivity.
- [ ] Define maximum session loss, maximum open risk, and permitted instruments.

## Market map

- [ ] Classify higher-timeframe regime: balance, imbalance, or transition.
- [ ] Mark external structure and the active range.
- [ ] Plot prior-day and weekly highs/lows, VAH, VAL, POC, major HVNs/LVNs, and event anchors.
- [ ] Compare BTC, ETH, relevant spot pairs, and perpetuals for confirmation or divergence.
- [ ] Identify where liquidity is likely concentrated.

## Conditional scenarios

- [ ] Write the primary continuation scenario.
- [ ] Write the failure or reversal scenario.
- [ ] State the evidence required for acceptance and rejection.
- [ ] Match each valid scenario to a named playbook setup.
- [ ] Define the no-trade zone and conditions.

{% hint style="success" %}
A complete plan should fit in a few sentences: context, location, conditions, play, and invalidation. More detail is not automatically more clarity.
{% endhint %}

## Readiness

- [ ] Sleep, focus, and emotional state are adequate.
- [ ] No pressure to recover losses or force a daily profit goal.
- [ ] Screenshots and journal template are ready.

If a critical item is unknown, reduce exposure or wait. Uncertainty is a position-sizing input, not a problem analysis must pretend to solve.
