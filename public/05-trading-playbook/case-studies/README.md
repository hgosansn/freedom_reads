# Worked Case Studies

These synthetic cases teach calculation and classification. Prices are illustrative, not historical claims. Each case reveals only information available at the stated decision point.

| Case | Main lesson |
|---|---|
| [Valid balance fade](valid-balance-fade.md) | Price a resting limit at a qualified edge |
| [Canceled balance fade](canceled-balance-fade.md) | Cancel when acceptance destroys the premise |
| [Failed auction non-fill](failed-auction-non-fill.md) | A correct thesis does not justify chasing |
| [Accepted or false breakout](accepted-vs-false-breakout.md) | Classify before choosing continuation or reversal |
| [Pullback in transition](trend-pullback-transition.md) | Reject a trend model when external context changes |

For every case, reproduce the ticket with the [Frozen Model Specification](../model-specification.md), then change one input at a time and state whether the order, size, or model changes.
